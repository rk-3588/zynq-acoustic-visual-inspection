# 显示看门狗验证

## 运行规则

看门狗每秒独立、只读采样VPP SOF计数。当UI进程有效、图层开启、摄像头MM2S／S2MM运行且错误掩码为0时，连续3个完整采样区间落在72～90次/秒，调用正常UI stop/start。每次尝试后冷却10秒。

计数复位、采样异常、UI更换、UI关闭和采集错误打断累计。恢复与手动服务操作共用服务锁，并检查UI和看门狗进程身份。正常停止失败时终止恢复流程；UI关闭同时停止看门狗。监控不读取Mixer完成事件寄存器。

## 板端功能

相册操作触发显示异常后，监控记录 `recovery_attempts=1 last_result=0`，UI重新启动，SOF恢复约60/s，VDMA错误掩码为0；屏幕画面和触摸恢复正常。最终v2程序在板端通过真实UIO检查，运行采样约60/s。

板端记录验证恢复功能，10秒冷却由模拟UIO进程测试覆盖。该机制按上述计数与采集条件触发，不参与声学算法或摄像头初始化。
