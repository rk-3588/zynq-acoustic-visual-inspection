# 机械臂实时区域交互验证

## 手动夹取

手动夹取读取定位服务的最新有效实时坐标。64×36网格按列0～20、21～42、43～63映射左、中、右区域。夹取页与确认窗口持续更新坐标和区域；短暂失效时保留窗口并禁用确认，恢复后可继续确认，窗口期限为10秒。

服务接受请求时独立重新读取目标区域，再应用 `robot-regions.conf` 映射。发送条件包括声学启用、active、数据年龄不超过150 ms、合法坐标、区域启用、任务互斥、持久化与nonce去重。

自动夹取使用稳定目标和1.5秒驻留；12区跟踪使用独立的区域切换与任务条件。

## 结果超时处理

夹取默认等待结果30秒。进入未知结果状态后保留提示5秒，关闭自动模式、清除连接确认并持久化转为本地READY。该转换不生成成功结果，不发送重试或下一条动作。任务号、nonce及最后已知完成ID保留。

匹配的迟到最终结果可在提示保留期内处理；转为READY后旧回包按非活动任务忽略。持久化与配置故障保持闭锁。
