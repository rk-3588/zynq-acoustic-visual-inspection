# 摄像头采集与相册验证

## 测试配置

OV5640输出1280×720，PCLK极性寄存器为 `0x4740=0x20`，分频寄存器为 `0x3035=0x21`。摄像头使用30 cm连接线，PCLK与GND配对绞合。测试程序为UI v29、snapshot v3、album v2。

## 采集结果

原速配置下S2MM状态记录过 `0x15190` 和 `0x1d190`，清除粘滞位后0.5秒内再次出现采集错误。分频配置下，多次读取的S2MM状态为 `0x11000`，错误掩码为0，写槽持续轮换，抓拍预检为ready。观测覆盖启动后约17～314秒。

## 抓拍测试

| 入口 | 耗时 | 结果 |
| --- | --- | --- |
| 命令行 | 779 ms | 保存成功 |
| 触摸按钮 | 886 ms | 保存成功 |

抓拍保留两遍像素比对与250 µs复制观测间隔保护。两次任务分别经过1次和4次保护间隔拒绝后重试成功，最终输出通过像素一致性、几何与错误状态检查。

## 相册测试

| 项目 | 结果 |
| --- | --- |
| 列表扫描 | total=5、bad=0，连续3次读取成功 |
| 缩略图 | 缓存命中，单次构建约10～23 ms |
| 照片详情 | 原图读取、CRC与640×360缩放通过，后端构建约128 ms |
| 触摸操作 | 抓拍、列表、照片详情、详细数据及关闭操作正常 |

这些耗时对应上述配置的具体测试样本。摄像头时钟参数、VPP事件计数与HDMI输出时序分别表示不同链路指标。
