# AC-16：声视融合检测与定位系统

基于 **Zynq-7020 FPGA** 的便携式声学相机，集成16路麦克风阵列、OV5640摄像头、HDMI触摸屏和机械臂串口接口，将声音位置、现场图像与交互控制结合起来。

PL并行完成声学成像、图像处理和视频合成；PetaLinux负责测量、触摸界面、抓拍记录与机械臂任务控制。

## 主要功能

- **声源可视化**：双环16麦阵列、200 Hz高通、延时求和、静音门控和动态色阶平滑，显示实时／稳定定位坐标。
- **图像处理**：原图、灰度、二值化、亮度偏移、反相和移位增益六种模式；支持全屏、手动ROI和声源跟随ROI。
- **触摸界面**：半透明测量侧栏、参数滑块、主峰频率、芯片温度及关机操作。
- **抓拍相册**：摄像头原图BMP＋同次读取的测量JSON，支持缩略图、照片浏览与测量详情。
- **机械臂联动**：通过UART连接独立控制器，支持手动／自动夹取、12区跟踪及测试动作。

## 平台配置

| 项目 | 配置 |
| --- | --- |
| FPGA | XC7Z020-CLG400-2 |
| 阵列 | 16个ICS-43434，双环半径25／50 mm |
| 声学 | 46.875 kHz采样，64×36能量网格 |
| 视频 | OV5640，1280×720，HDMI输出 |
| 系统与工具 | PetaLinux、Vivado／Vitis 2026.1 |

频率来自单麦FFT，测量记录为同次软件请求；网格能量不作为已标定声压级。
